# Custom dashboard inquiry

CTA: **Request a dashboard for my lab**

Pricing: **Custom dashboards from $999. Final pricing depends on scope.**

The CTA links to https://midauthorbio.com/#contactdash. No email client, report files or account are needed. The existing website contact form has not been changed by this frontend update.

## Suggested website form

Require contact details, the goal and a data summary. Keep other fields optional for the initial inquiry.

1. **Contact:** Name, work email and lab/institution.
2. **Goal:** What questions or tasks should the dashboard help your lab address?
3. **Data:** What data types and file formats will it use? Approximately how many samples/genomes and how much data? Are the results already analyzed, or is analysis also needed?
4. **Features:** Which views and actions are essential (plots, search/filters, comparisons, downloads, uploads)? An example dashboard or screenshot is helpful.
5. **Access and hosting:** Who will use it? Should access be public or require login? Hosted by MAB, downloadable/offline, or installed at your institution?
6. **Updates:** Is this a fixed dataset or an ongoing project? How often will data change, and should updates or analyses run automatically?
7. **Timing and budget:** What is the desired delivery date and approximate budget range? Budget is optional.

Optional reference: GToTree result code or example report link.

After review, provide a written quote defining deliverables, supported inputs, revisions, hosting/maintenance and any recurring costs. The starting price is not an offer to deliver every dashboard for $999.
